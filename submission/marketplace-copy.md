# Marketplace copy (shared)

## Plugin name

**AudioDN** (short for Audio Delivery Network)

Marketplace identifiers stay `audiodn` (lowercase kebab-case). The human-readable title is `AudioDN`.

## Short description

A hosted place for agents to store, play, and preview audio — plus the APIs to put it in your app.

## Long description

AudioDN (Audio Delivery Network) is hosted audio infrastructure. Add it to a Cursor bot or any app when you need a durable place to keep audio that agents come across — generated clips, downloads, voice notes, podcasts, UGC — then play, preview, and reuse those tracks. This plugin teaches coding agents the correct security boundaries and API sequences, and wires the hosted AudioDN MCP server (docs without a key; live store/play tools after you paste an API Access key).

It is the AudioDN plugin for AI coding tools — not a separate product. Use it with Cursor, Claude Code, or OpenAI/Codex when building music, podcast, voice, or UGC audio features without reinventing S3, queues, and FFmpeg pipelines.

**Important:** Creating an upload session does not itself return the final upload URL for each track. Each track requires its own track-creation request. Server API Access keys must never appear in browser or mobile code.
