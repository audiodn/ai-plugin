## Plugin name

AudioDN

## Short description

Build secure audio upload, format standardization, and playback with AudioDN — skills, workflows, and MCP for coding agents.

## Long description

AudioDN (Audio Delivery Network) is hosted audio infrastructure: upload sessions, per-track signed upload URLs, transcoding to consistent playback variants, waveforms, and signed delivery. This plugin teaches coding agents the correct security boundaries and API sequences, and wires the hosted AudioDN MCP server for grounded docs and optional live API tools.

It is the AudioDN plugin for AI coding tools — not a separate product. Use it with Cursor, Claude Code, or OpenAI/Codex when building music, podcast, voice, or UGC audio features without reinventing S3, queues, and FFmpeg pipelines.

**Important:** Creating an upload session does not itself return the final upload URL for each track. Each track requires its own track-creation request. Server API Access keys must never appear in browser or mobile code.
